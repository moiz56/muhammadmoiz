EduRAG

LlamaIndex, FAISS, FastAPI, LangGraph, Qwen 0.5B

A retrieval-augmented question answering system for study material. It ingests textbooks, PDFs, DOCX files, and web articles into a FAISS index and serves source-grounded answers through a FastAPI backend, so every answer points back at the passage it came from.

On top of retrieval, a LangGraph workflow driven by Qwen 0.5B generates multiple-choice questions from retrieved passages, then validates and cites them, regenerating any question that fails its own checks. The interesting part was getting a small model to be reliable by structuring the workflow around it rather than by scaling it up.

AI-Driven Crowd Counting

PyTorch, CNNs, Density Estimation

A density-estimation network for counting people in dense scenes, combining a VGG-16 backbone with Squeeze-and-Excitation blocks, multi-scale context modules, and dilated convolutions to handle the wide variation in head size across a single frame.

On ShanghaiTech Part B it reaches 10.38 MAE and 16.2 MSE, ahead of MCNN (26.4), Switching CNN (21.6), and CSRNet (10.6), at 0.15 seconds per image.

Image Format COnverter

Python, Watchdog, Pillow, Pytest

Sometimes its just annoying to go to a file converter online to convert a file from a png to jpg or a .webp to a .jpg. A simple too I built where a file watcher looks over your folder recursively and anytime an extension is changed it converts the format to the desired format in the background

TCP File Transfer Utility

C, Python, Tkinter, POSIX Sockets

A file transfer client and server written in C on top of Berkeley sockets, built to understand what reliable streaming actually requires once you are below the library level.

A Tkinter front end drives the two processes using fork(), pipe(), and dup2() to wire up file descriptors between them, which turned out to be a better lesson in process control than the networking itself.
